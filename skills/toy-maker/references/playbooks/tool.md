# 工具类 Toy 手册（查询 / 计算 / 规划 / 模拟器 / 生成器 / 玩家互助）

分类：`TOOL`。约 460 个作品，官方明说「工具赛道相对不拥挤」，本周必玩入选比例远高于数量占比。
头部作品：某射击游戏的数据查询 + 开箱模拟、二游宠物/角色交换匹配、抽卡/资源规划手账、提示词生成器。

## 成功结构
1. **一个具体人群的一个具体痛点**：「某游戏玩家想知道 X」「某活动要规划 Y」。越窄越好用。
2. **3 秒出结果**：首屏就是输入/选择区，不要介绍页；默认值就能看到一个示范结果。
3. **数据要准、要新**：版本更新当天跟进；页面标注数据更新日期。
4. **个人化**：记住用户的配置/库存/清单（云存档），下次打开直接是「我的」。

## 增长与留存
- 官方数据：垂类工具 / 资料库复玩率 49%，全类型最高——内容跟着游戏版本更新，是最适合长跑的底盘。
- 规划/手账类收藏率全站最高（每千次 ~40）——「收藏方便回来」是核心留存，首页提示一次即可。
- 玩家匹配/交换类评论率高：评论区变成找搭子的地方。需要跨玩家撮合就得**自建后端**（需先开通权限），
  SDK 的云存档只能存自己的数据，不能跨玩家读。
- 跟游戏版本节奏走：版本更新日发视频 + 更新 Toy。
- 版本号高（30+）是常态：持续修数据就是运营。

## 推荐 SDK
`setCloudStorage/getCloudStorage`（配置、清单）、`getUserProfile`（昵称展示，或系统生成代号）、
`saveImageToAlbum`（规划结果出图）、`getQrCode`（PC 规划好扫码到手机）、`navigate`（跳攻略视频/作者主页）。

## 坑
- 「福利领取」「组队互助」「信息差」类工具游玩高但几乎零互动，而且容易触碰诱导、站外利益等红线——不要对标。
- 不得接入第三方登录、不得跳站外（官方 wiki 等可蓝链的站内域名除外）。
- 引用游戏官方素材、数据要注意版权和数据来源说明。
- 用户自填的库存/需求如果展示给其他玩家，属于 UGC：限制为结构化选项（下拉/勾选），文字过 `checkInputSafety`。
- AI 生成类工具：不能让用户输入任意文本后公开展示生成结果；生成内容只自己可见。
