# 互动玩法类 Toy 手册（音乐玩具 / 创作玩具 / 捏人 / 互动展览 / 教育互动）

分类：`INTERACTIVE_PLAY`。约 320 个作品，必玩入选比例高；**不受「游戏」分类的未成年人限制**。
头部作品：可以随时玩的术曲节奏玩具、笔画变形图案、捏捏乐/捏人、像素风改编、独立美术展、物理电路小实验。

## 成功结构
1. **玩具而不是关卡**：没有失败，打开就能摆弄；乐趣来自「我做出来的东西」。
2. **产出物**：一段旋律、一张图案、一个捏好的角色——产出物是分享和收藏的理由。
3. **内容可扩展**：曲库、贴纸、部件、展品持续上新（头部音乐玩具 140+ 个版本）。
4. **图鉴/收集**：已解锁部件、已玩曲目，给回访理由。

## 增长与留存
- 分享数最高的作品是捏人类：接了 `share` + `getQrCode` + `saveImageToAlbum`，把「晒作品」做进流程。
- 奖励面板：给指定视频投币/关注作者领图鉴、皮肤；配里程碑和节日/联动内容（只能是额外奖励）。
- 教育类（物理、化学、历史互动）：工具感强、收藏率高，适合 UP 主的知识区视频配套。

## 推荐 SDK
`saveImageToAlbum` / `getQrCode` / `share`、`setCloudStorage`（作品存档 ≤1024 字节/key，复杂作品要压缩编码）、
`getAuthorRelation` / `getVideoUserActions`（解锁部件）、`requestMicrophone`（声音玩具，用完 `stopMedia`）。

## 坑
- **自由绘制、上传图片、拍照公开都是 UGC 红线**：作品只在本地展示/保存；含自由绘制必须开 `--watermark`。
- 作品内文字输入要过 `checkInputSafety`，或改成预置贴纸/文字。
- 音乐/音效版权：用原创或已授权素材；虚拟歌手声库按其使用条款。
- 产出图如果画进了外域图片（头像等）会污染 Canvas，导出失败。
