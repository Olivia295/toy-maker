# 整活 / 生成器 / 模拟器类 Toy 手册（梗转盘 / XX 模拟器 / 鬼畜生成）

分类：多数在 `OTHER`，也有放 `TOOL`/`GAME` 的。约 480 个作品。头部：梗 wiki 转盘、玄幻/人物模拟器、
鬼畜生成器、抽奖模拟器。特点是**爆得快、衰得快**。

## 成功结构
1. **一个梗，一个动作**：转一下、点一下、生成一下——3 秒出一个好笑的结果。
2. **结果随机 + 可重来**：每次不一样，「再来一次」是核心循环。
3. **结果可晒**：截图友好的结果画面；配一句可以直接当评论发的文案。
4. **社区共创的味道**：梗库来自评论区投稿（作者人工收录进代码，不是用户直接上传）。

## 增长与留存
- 官方数据：热梗二创复玩率 37%，但「梗一过就没人再来」，不适合当长期底盘；热点类 10w+ 命中率高，关键是热梗出现 **3–7 天内**上线，标题和封面直接写梗名，必须自己配视频分发。
- 跟梗的热度走：配一条竖屏视频同步上线；热度过了就转成「合集里的一个」。
- 评论区征集新梗 → 下个版本加入并署名致谢（文本由作者审核后写进代码，不开放用户输入）。
- 转盘/抽签类可加「今日运势」类每日回访点（云存档记录当天结果）。

## 推荐 SDK
`saveImageToAlbum` / `getQrCode` / `share`、`getUserProfile`（结果里出现自己的昵称最好笑）、
`setCloudStorage`（每日结果、收集图鉴）、`navigate`（跳梗出处视频）。

## 坑
- 梗涉及真人（UP 主、主播、明星）要尊重本人，避免侮辱、造谣、引战；涉政涉黄一律不碰。
- 鬼畜素材的音视频版权；尽量原创或用已授权素材。
- 让用户自定义转盘内容并公开展示 = UGC：只允许本地使用，或预置选项；自由绘制要开水印。
- 模拟真实机构/App 界面要显著标注「非真实」。
