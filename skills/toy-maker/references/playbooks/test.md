# 测试类 Toy 手册（人格测试 / 指数测试 / 属性测试）

分类：`TEST`。赛道约 125 个作品，单品天花板最高，但「本周必玩」几乎不选——增长靠自传播。

## 成功结构
1. **钩子**：借一个大家熟悉的框架再拧一下（「X 已经过时，Y 来了」「测测你是哪种 Z」），首屏一句话 + 开始按钮。
2. **预期**：按钮旁写题数/时长（「20 道互动选项」「1 分钟」）。题量 10–25 题最常见。
3. **题目**：情境化、带梗，不要问卷腔；每题 3–4 个选项，偶尔一道「彩蛋题」。
4. **结果**：这是作品的全部价值所在——
   - 有名字的类型（不是分数），每个类型一张**可截图的结果卡**：称号、插画、3 条说中你的描述、一句毒舌/温柔点评、稀有度（「全站 x% 的人」）。
   - 类型数 8–16 个，让朋友之间结果不同，才有比较和讨论。
   - 结果页给「和谁最配 / 最不配」，制造 @ 朋友的理由。
5. **复玩**：「重新测试」+ 「查看全部类型图鉴」。

## 增长与留存
- 测试的评论率是全站最高（每千次游玩 3–5 条）：在结果页直接写「评论区晒出你的类型」，评论区就是传播场。
- 结果卡：`saveImageToAlbum`（App）/ `<a download>`（Web），卡面印 `getQrCode()` 二维码。
- 发布配套视频：「我测了全站的 16 种类型」，视频绑定 Toy。
- 粉丝向测试（某偶像/某角色属性）要尊重本人和版权方，避免引战。

## 推荐 SDK
`getUserProfile`（结果卡上写昵称，拒绝就用「旅行者」之类默认称呼）、`saveImageToAlbum` / `getQrCode` / `share`、
可选 `setCloudStorage` 记住上次结果、`getAuthorRelation` 关注后解锁「隐藏类型」或「详细解读」（主结果必须免关注可见）。

## 坑
- 不能让用户自己输入昵称展示在结果卡上；不要收集生日、真实姓名等个人信息。
- 「运势/命理」类保持正向、标「仅供娱乐」，不做健康/财运/婚恋等具体预测。
- 结果不能全是夸，也不能刻薄到伤人；涉及性别、身材、地域的标签要格外小心。
- 题目和结果文案全部原创；借用 MBTI 等框架时别冒充官方测评。
