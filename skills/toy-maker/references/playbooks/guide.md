# 攻略类 Toy 手册（图鉴 / 卡组库 / 收集对照表 / 逛展指南）

分类：`GUIDE`。只有约 50 个作品——几乎空白的赛道。头部：卡牌游戏卡组与卡包一览、二游逸闻收集对照、
抽卡模拟、展会逛展工具、开放世界游戏图鉴。

## 成功结构
1. **比 wiki 好用的一件事**：可筛选、可勾选「我已收集」、可搜索、离线也快。
2. **个人进度**：勾选状态存云端（`setCloudStorage`），回来接着用——这是攻略区别于网页 wiki 的地方。
3. **跟版本**：头部攻略 180+ 个版本；标题里写「已更新 x.x 版本」。
4. **移动端优先**：一手拿手机一手玩游戏，单手可操作、字号大、深色模式。

## 增长与留存
- 收藏率高（每千次 ~15）：在首页提醒收藏。
- 和攻略视频互相导流：视频简介挂 Toy，Toy 内 `navigate({type:'video'})` 到对应讲解视频。
- 展会/活动类：活动前一周上线，活动结束后转成「回顾」。

## 推荐 SDK
`setCloudStorage/getCloudStorage`（收集进度，128 key 上限，用位图压缩大量勾选）、`navigate`、
`getQrCode`（PC 查好扫码到手机）、`getAuthorVideos`（自动列出作者的攻略视频）。

## 坑
- 游戏截图、立绘、数据的版权：标注来源，避免整站搬运；不使用他人商标做图标。
- 跳转只能到站内（含 wiki.biligame.com 等可蓝链域名），不能跳外部 wiki。
- 数据量大时别塞进入口 index.html（1MB 上限），拆成 JSON 按需 fetch。
