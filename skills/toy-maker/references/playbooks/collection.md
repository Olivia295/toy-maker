# 合集类 Toy 手册（作者作品集 / 主题精选 / 个人主页）

分类：`COLLECTION`。只有约 35 个作品。头部：作者自己的游戏合集、互动作品入坑精选、个人主页式合集。

## 成功结构
1. **导航价值**：解决「在 App 里很难找回玩过的 Toy」——一个入口进所有作品。
2. **有编辑观点**：不是列表，是「新手先玩这 3 个」「按心情选」「本月新作」。
3. **卡片化**：每个作品一张卡（封面、一句话、时长、类型），点击 `navigate({type:'toy', id})` 跳转。
4. **持续更新**：新作上线就加，合集版本号高（160+）是常态。

## 增长与留存
- **官方建议：Toy 数量到了几十个再建个人合集页**；只有 1–3 个就建，等于造了个没人进的空房间。新人阶段把力气放在单个 Toy 的公开发布 + 视频挂链上。
- 作品够多时，合集降低老粉的选择成本，新作也能借老作品的流量冷启动。
- 精选别人的作品要有理由和评语，并尊重原作者（只用公开信息、链接到原 Toy）。
- 可做「通关打卡」：用云存档记录玩过哪几个，给全部玩过的玩家一个称号。

## 推荐 SDK
`navigate`（type: toy / video / space）、`getAuthorProfile` / `getAuthorVideos`（自动展示作者信息与视频）、
`setCloudStorage`（打卡进度）、`getAuthorRelation`（粉丝专属区，额外内容）。

## 坑
- 不能 iframe 嵌入其他 Toy 或外部网页，只能跳转。
- 别把合集做成纯导流页：至少有一份免交互即可用的内容（精选评语、打卡、推荐逻辑）。
- 引用他人作品封面要注意版权；不确定就只用标题和文字介绍。
